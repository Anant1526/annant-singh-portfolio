Annant Singh — Portfolio (Full Working Backend)

========================================
OPTION 1 — Express (recommended)
========================================
  npm install
  npm start

  Open: http://localhost:3000

========================================
OPTION 2 — Zero install (Node only)
========================================
  node server-native.js

  Open: http://localhost:3000

========================================
FEATURES
========================================
- Full multi-page portfolio (Home, About, Skills, Projects, Blog, Contact)
- Working contact form → saves to messages.json
- View messages: http://localhost:3000/api/messages
- Profile photo included
- Social media SVG icons (replace # with your real links)

Files:
  server.js         → Express server
  server-native.js  → Pure Node (no npm needed)
  package.json      → Express dependencies
  messages.json     → Created automatically when form is submitted

Replace contact placeholders and social # links with your real details.
